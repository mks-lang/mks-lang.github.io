## 2025-05-15 - [Screen Reader Clarity & Feedback]
**Learning:** Keyboard shortcut hints (like "(/)") are helpful in placeholders but create auditory noise when included in `aria-label`. Additionally, decorative background canvases and UI "flair" (like console dots) without semantic meaning should be explicitly hidden from screen readers to reduce cognitive load. Providing immediate, polite feedback (`aria-live="polite"`) on filtered search results (empty states) is essential for an accessible search experience.
**Action:** When adding search inputs, keep shortcut hints in the `placeholder` only and use a clean `aria-label`. Always apply `aria-hidden="true"` to decorative `<canvas>` or purely aesthetic elements. Ensure all dynamic empty state containers use `aria-live="polite"`.
